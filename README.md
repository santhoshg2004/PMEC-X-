# 🚀 PMEC-X: Cloud Energy Optimization System

PMEC-X (Predictive Multifactor Energy Consolidation) is a simulation-based cloud scheduling system designed to optimize energy consumption, improve VM utilization, and minimize SLA violations in data centers.

---

## 📌 Key Features

- 🔋 Reduces energy consumption by ~20%
- ⚡ Intelligent VM consolidation
- 📉 Zero SLA violations achieved
- 📊 Compares multiple scheduling algorithms:
  - PMEC-X
  - Round Robin
  - MinMin
  - FCFS

---

## 🧠 Technologies Used

- Python
- Simulation Modeling
- Cloud Computing Concepts
- Data Analysis
